# 8-Week DSA Intensive Study Plan for Google Senior SWE Interview

**Goal:** Prepare for Google Kenya senior software engineer interview in 2 months  
**Constraint:** Full-time employment (1-2 hours daily study)  
**Interview Date:** ~Week 9-10  
**Difficulty:** Intermediate-Advanced (rusty engineer with strong fundamentals)

---

## 📋 High-Level Strategy

This plan balances:
- **Breadth** (cover all major topics)
- **Depth** (master problem patterns, not just memorize)
- **Time-efficiency** (1-2 hours/day only)
- **Mock interviews** (practice under pressure)

### Key Principles
1. **Spaced Repetition:** Review problems from previous weeks
2. **Pattern Recognition:** Focus on solution patterns, not brute-force memorization
3. **Active Recall:** Write solutions from scratch, don't just read
4. **Progressive Difficulty:** Start with fundamentals, ramp up complexity
5. **System Design Prep:** Light system design in weeks 7-8

---

## 📅 Weekly Breakdown

### **Week 1-2: Foundation Refresh** (Sep 2 - Sep 15)
**Theme:** Core Data Structures & Time Complexity Review

**Topics:**
- Arrays & Strings (2D arrays, manipulation)
- Linked Lists (singly, doubly, circular)
- Hash Maps / Sets
- Big O Analysis refresh
- Recursion basics

**Weekly Goal:** 5-6 problems/day at Easy-Medium difficulty  
**Time Allocation:**
- 30 min: Concept review + examples
- 60 min: 2-3 problems (solving + code review)
- 30 min: Refinement + notes

**Key Focus Areas:**
- Array manipulation (two pointers, sliding window)
- String problems (anagrams, palindromes, substrings)
- Linked list manipulation (reverse, merge, cycle detection)
- Hash table for counting/frequency

---

### **Week 3-4: Intermediate Data Structures** (Sep 16 - Sep 29)
**Theme:** Trees, Graphs & Advanced Structures

**Topics:**
- Binary Trees (traversals, DFS, BFS)
- Binary Search Trees
- Heaps & Priority Queues
- Graphs (adjacency list/matrix, DFS, BFS)
- Tries (for string problems)

**Weekly Goal:** 4-5 problems/day at Medium-Hard difficulty  
**Time Allocation:**
- 30 min: Concept review + visualization
- 75 min: 2-3 problems (solving + review)
- 15 min: Edge cases & optimization

**Key Focus Areas:**
- Tree traversals (all types)
- Graph connectivity & shortest path
- Level-order traversal patterns
- Priority queue applications

---

### **Week 5-6: Algorithms & Problem Patterns** (Sep 30 - Oct 13)
**Theme:** Dynamic Programming, Sorting, Searching

**Topics:**
- Sorting algorithms & stability
- Merge sort, Quick sort, Heap sort
- Binary Search & variants
- Dynamic Programming fundamentals
- Backtracking & DFS patterns
- Greedy algorithms

**Weekly Goal:** 4-5 problems/day at Medium-Hard difficulty  
**Time Allocation:**
- 20 min: Algorithm concept + walkthrough
- 80 min: 2-3 problems (solving + optimization)
- 20 min: Complexity analysis & alternatives

**Key Focus Areas:**
- DP recurrence relations
- Backtracking patterns (combinations, permutations, N-Queens)
- Greedy choice property validation
- Sorting stability & in-place requirements

---

### **Week 7: Intensive Practice & Pattern Review** (Oct 14 - Oct 20)
**Theme:** Weak Area Focus + Mock Interviews

**Topics:**
- Review of weak problem categories
- Mixed difficulty problems (random selection)
- Light System Design (1-2 problems)
- Mock interview practice

**Weekly Goal:** 5-6 problems/day + 1 mock interview  
**Time Allocation:**
- 90 min: 3-4 mixed problems
- 60 min: 1 mock interview (timed, no hints)
- 30 min: Code review & improvements

**Key Focus Areas:**
- Problem identification & approach
- Time management under pressure
- Communication clarity
- Edge case handling

---

### **Week 8: Final Push & Mock Interviews** (Oct 21 - Oct 27)
**Theme:** Mock Interviews & Confidence Building

**Topics:**
- 2-3 full mock interviews
- Problems from previous weeks (speed runs)
- System design quick problems
- Behavioral prep

**Weekly Goal:** 2-3 mock interviews + 10-15 review problems  
**Time Allocation:**
- 90 min: Full mock interview (timed)
- 30 min: Debrief + notes
- 30 min: 2-3 review problems

**Key Focus Areas:**
- Interview communication
- Managing time across multiple problems
- Debugging under stress
- Final confidence boost

## ⚠️ Common Pitfalls to Avoid

1. **Passive Learning:** Watching solutions without attempting first
2. **Speed Over Understanding:** Solving problems fast but not understanding patterns
3. **Ignoring Weak Areas:** Skipping topics that feel hard
4. **No Mock Interviews:** Practicing alone doesn't simulate pressure
5. **Inconsistency:** Missing days breaks momentum—aim for 5-6 days/week
6. **Not Optimizing:** Stopping after finding a solution (should optimize)
7. **Skipping System Design:** Even for senior roles, DS prep is important context
