# Resources & References Guide

## Online Judge Platforms

### Primary: LeetCode
- **Pros:** Largest problem database, excellent discuss section, filter by topic
- **Link:** leetcode.com
- **Recommended Plan:** Get Premium ($160/year or monthly)
- **Usage:** Main problem source, organized by topic

### Secondary: GeeksforGeeks
- **Pros:** Detailed explanations, tutorial style, algorithm visualizations
- **Link:** geeksforgeeks.org
- **Usage:** Concept learning before problems

### Mock Interviews: Interviewing.io
- **Pros:** Real interviewers, pressure simulation, feedback
- **Link:** interviewing.io
- **Cost:** $99/session
- **Usage:** Week 7-8 practice (do 2-3 sessions)

### Alternative: Pramp.com
- **Pros:** Free peer-to-peer interviews, good for casual practice
- **Link:** pramp.com
- **Cost:** Free
- **Usage:** Week 7-8 supplement

## Time Management Strategies

### Pomodoro Technique
- 25 min focused coding
- 5 min break
- Repeat 2-3 times
- 15-30 min long break

### Best Study Times
- **Mornings (6-7 AM):** Fresh mind, high quality
- **Evenings (7-9 PM):** After work, before fatigue
- **Avoid:** Late night (quality drops)

### Weekly Time Allocation
```
Total Weekly: 10-14 hours
- Monday-Friday: 2 hours/day (10 hours)
- Weekend: 2 hours optional (0-4 hours)
- Flexibility: Adjust based on work schedule
```

## Quick Reference: Big O Complexity

### Common Time Complexities (Best to Worst)
```
O(1)       - Constant (array access)
O(log n)   - Logarithmic (binary search)
O(n)       - Linear (simple loop)
O(n log n) - Linearithmic (merge sort, heap sort)
O(n²)      - Quadratic (bubble sort, brute force nested loops)
O(n³)      - Cubic (three nested loops)
O(2^n)     - Exponential (subset generation)
O(n!)      - Factorial (permutations)
```

### Data Structure Complexity

| Operation | Array | LinkedList | Hash Map | BST | Heap |
|-----------|-------|-----------|----------|-----|------|
| Search | O(n) | O(n) | O(1) avg | O(log n) | O(n) |
| Insert | O(n) | O(1) | O(1) avg | O(log n) | O(log n) |
| Delete | O(n) | O(1) | O(1) avg | O(log n) | O(log n) |
| Space | O(n) | O(n) | O(n) | O(n) | O(n) |

## Problem Difficulty Progression

```
Week 1-2:  Easy (mostly), Medium (1-2)
Week 3-4:  Medium (mostly), Hard (1-2)
Week 5-6:  Medium-Hard mix, Hard more frequent
Week 7-8:  Hard focused, Mock interviews
```

### Difficulty Assessment
- **Easy:** Solvable in 10-15 min with basic approach
- **Medium:** Requires pattern recognition, 20-30 min
- **Hard:** Requires multiple patterns, 30-45+ min
