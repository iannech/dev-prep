## Key Concepts to Implement

### Tree Traversals (Must implement from scratch)
```
1. Inorder (Left, Root, Right)
2. Preorder (Root, Left, Right)
3. Postorder (Left, Right, Root)
4. Level Order (BFS)
5. Zigzag Level Order
```

### Graph Algorithms
```
1. DFS (recursive & iterative)
2. BFS (queue-based)
3. Topological Sort
4. Cycle Detection
5. Connected Components
```

### Heap Operations
```
1. Insert/Delete in O(log n)
2. Heapify (build heap)
3. Priority Queue implementation
4. K-th largest/smallest patterns
```
