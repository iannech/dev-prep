# Week 7-8: Intensive Practice & Mock Interviews

## Week 7: Review & Mixed Practice

### Strategy
- Focus on **weakest topics** from Weeks 1-6
- Solve 5-6 random problems daily

### Problem Selection
**Weak Area Identification Process:**
1. List all problem categories solved (Arrays, LL, Trees, DP, etc.)
2. Identify 2-3 categories with lowest success rate
3. Prioritize those categories in Week 7
4. Solve only Medium-Hard difficulty problems

## Problem Review Checklist

For **every** problem solved, ask:

- [ ] Did I understand the problem statement?
- [ ] Did I ask clarifying questions?
- [ ] Did I communicate my approach before coding?
- [ ] Did I code cleanly and explain my logic?
- [ ] Did I consider edge cases?
- [ ] Did I test with examples?
- [ ] Can I optimize further (time/space)?
- [ ] Did I analyze complexity correctly?
- [ ] Can I solve it again from scratch?
- [ ] What pattern did this problem teach?

## Mock Interview Scoring Rubric

### Self-Score (out of 5)

**Communication** (1-5):
- 5: Clear approach, great clarification questions
- 3: Adequate explanation, some clarity issues
- 1: Hard to follow logic, no discussion

**Code Quality** (1-5):
- 5: Clean, well-structured, readable
- 3: Works but has some inefficiencies
- 1: Unclear, hard to follow

**Problem-Solving** (1-5):
- 5: Optimal solution found, good optimizations
- 3: Working solution, suboptimal
- 1: Only partial solution

**Time Management** (1-5):
- 5: Solution + optimization + testing in time
- 3: Solution achieved but rushed on testing
- 1: Ran out of time

**Edge Cases** (1-5):
- 5: Comprehensive edge case handling
- 3: Covered most edge cases
- 1: Missed key edge cases

**Total Score:** Average of above (treat as progress tracker, not absolute measure)

## Post-Interview Reflection

After your actual interview:

1. **Immediately After (while fresh):**
   - Write down problems you faced
   - Your approach and solution
   - What you'd improve

2. **Analysis (next day):**
   - Research optimal solutions
   - Understand what you missed
   - Note patterns to revisit

3. **Learning (week after):**
   - Do similar problems again
   - Solidify patterns that tripped you up

**Remember:** Interview performance depends on:
1. **Preparation** (50%)
2. **Communication** (30%)
3. **Problem-solving ability** (20%)

You control all three. Focus on showing your thought process clearly.
